# Vibe Coding – Quantiphi | NIT Surat

## Problem Statement: AI Chat Assistant

### The Mission
Build an intelligent chat interface with real-time capabilities.

### Frontend UI & User Interaction

- **Chat Interface:** A scrollable conversation view with distinct chat bubbles for user and AI.
- **Streaming View:** Text appearing character-by-character to simulate real-time processing.
- **History Sidebar:** List of past conversation threads for easy retrieval.

### Backend Logic & State Management

- **API Integration:** Connects to OpenAI or Claude API endpoints.
- **Persistence:** MongoDB stores the conversation object, including timestamp, user prompt, and AI response.

### The Vibe Check

Add a **"Tone Toggle."** Allow the user to select **"Professional," "Casual,"** or **"Concise."** The backend must pass this preference as a **"system instruction"** modifier to the AI API request, changing the style of the response instantly.

Additionally, suggest and include **two extra features** that are not listed above, based on your understanding of chatbot capabilities.
